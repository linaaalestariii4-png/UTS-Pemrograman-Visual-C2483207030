# Aplikasi Kasir Kantin Kampus

## Deskripsi

Aplikasi Kasir Kantin Kampus merupakan aplikasi desktop sederhana berbasis Java yang digunakan untuk menghitung total pembelian makanan atau minuman serta uang kembalian pelanggan.

## Fitur Aplikasi

- Input nama makanan atau minuman.
- Input harga satuan.
- Input jumlah pembelian.
- Input uang pembayaran.
- Menghitung total harga.
- Menghitung uang kembalian.
- Validasi input dan pembayaran.
- Tombol Hitung, Bayar, dan Reset.

## Teknologi

- Java
- Java Swing
- NetBeans IDE

## Cara Menjalankan

1. Buka project melalui NetBeans IDE.
2. Jalankan aplikasi.
3. Masukkan data pembelian.
4. Klik tombol Hitung dan Bayar.
